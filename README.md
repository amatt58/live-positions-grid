# Live Positions Grid

A portfolio positions grid that loads positions over REST and updates them with simulated live prices. All data is simulated.

## Status

Early setup. The project scaffold and tooling are in place; the grid itself is not built yet.

## Stack

Vite, React 19, TypeScript (strict), Biome, Vitest. Node 24.

## Getting started

    npm install
    npm run dev

## Scripts

- `npm run dev`: dev server on port 5173
- `npm run check`: typecheck, lint and tests
- `npm run build`: production build
